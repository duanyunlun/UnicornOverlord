# 浏览器版构建与部署

## 范围

网站入口为 `web/index.html`。存档和普通MOD使用浏览器原生API，关卡/战术/默认装备复用上游React组件。文本/CPK编辑暂不提供。分类沿用技能、战斗、角色、职业、据点、采矿、商店、编队；任务编排只在编队内显示。

底部保存工程包括任务组件的编辑状态；导出合并选中的普通模块与任务编辑，先检查全部写入字节冲突。任务编辑器仍保留上游JSON/ZIP兼容入口与独立导出。pchtxt载入只影响预览，不自动转为工程修改。

## 构建

需要Node.js 24及npm，在仓库根目录运行：

```sh
npm ci --prefix web/mission --cache "$PWD/.tools/npm-cache"
npm test --prefix web
npm run build --prefix web/mission
npm run build --prefix web
python3 -m http.server 8766 --bind 127.0.0.1 --directory web/dist
```

浏览器打开 `http://127.0.0.1:8766/`。构建器仅复制明确允许的前端文件、编辑目录、补丁模板和许可；不会复制`.testdata`、`.extracted`、`.tools`及源存档。`mission_catalog.json.gz`是gzip文件，不要额外配置`Content-Encoding: gzip`。

浏览器回归脚本为`web/browser-smoke.mjs`，需要Playwright及浏览器。可在`.tools/web-tests`安装Playwright，通过`BROWSER_EXECUTABLE`指定浏览器路径；生成的测试文件和截图仅在`.tools/browser-validation`中。

## 发布

`.github/workflows/pages.yml`在main相关文件更新时构建、测试并通过GitHub Actions发布`web/dist`。原生版本手动发布工作流不受影响。

已发布地址：<https://duanyunlun.github.io/UnicornOverloardEditor/>。2026-09-05，Actions运行`33969572309`成功，线上HTTP 200；在实际线上URL运行`web/browser-smoke.mjs`通过。部署成功与页面实际可访问已分别验证。

## 限制

需要支持File API、DataView与DecompressionStream的现代浏览器。经验倍率、动态等级仅支持欧美版v1.0.5。所有新增补丁仍待游戏内验收；静态测试不等于实机通过。共享装备不会自动克隆，必须确认全局影响。
